# mac-control system map

This is a proposal-stage system map. The root Compass, owner-only safety
contract, provider boundaries, code, tests, and runtime evidence remain
authoritative.

## Load order

1. Read `CONTEXT.md` for guarded invocation and evidence boundaries.
2. Read `_meta/schema.md` before adding cards.
3. Use `objects/_index.md` to choose a bounded noun slice.
4. Verify source citations before marking a card verified.

No `processes/` or `effects/` shelf exists yet.

## Authority

- `.project-compass/` owns intent, child purpose, quiz answers, and alignment.
- This map owns only proposed structure and citations.
- A provider can supply evidence but cannot silently become the authority for
  visible behavior.
