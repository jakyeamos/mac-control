# Repository context index

Load this index by default, then read only the packets needed for the current task.

- `README.md` — repository overview and entry points.
- Root `AGENTS.md` — operating invariants.
- Add `commands.md`, `architecture.md`, `gotchas.md`, or `deploy.md` only when the repository has evidence that the packet is needed.

Do not dump the whole repository into an agent context. Keep this index short and update links when the referenced surfaces change.
